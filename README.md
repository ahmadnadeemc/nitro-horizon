# Nitro Horizon

A 3D arcade racing game in the browser, built with [Three.js](https://threejs.org) (WebGL).
The whole game is one file, `index.html`. Tracks, cars, textures, sound effects and music are all generated by code.

## Features

- Two tracks: **Sunset Coast** (hills, forests, mountains, ocean) and **Neon Night** (city, neon signs, wet road).
- Three cars with different top speed, acceleration and handling, and eight paint colours.
- Five AI rivals that brake for corners, overtake and use nitro. Easy, Normal and Hard settings.
- Drifting with tyre smoke and skid marks, a nitro boost, wall sparks and camera shake.
- HDR lighting, shadows, bloom glow, reflective car paint.
- Speedometer, minimap, live standings, lap times and a saved best lap per track.
- Engine sound that follows speed and gears, and a synthwave soundtrack.
- Keyboard, gamepad and touch controls. Low, Medium and High graphics settings.

## How the code is organised (`<script type="module">` in `index.html`)

1. **Utils**: maths helpers, seeded random numbers, smooth noise.
2. **Settings and renderer**: quality presets, WebGL renderer, bloom post-processing.
3. **Textures**: road, curbs, grass, signs and windows drawn on canvases.
4. **Tracks**: a closed spline through control points, sampled into 2400 points with banking and an AI speed profile.
5. **World**: sky, lights, terrain that blends into the road, road ribbons, barriers, trees, city, signs.
6. **Cars**: car bodies made by extruding a smooth side profile, wheels, lights, nitro flames.
7. **Physics and AI**: arcade grip and drift model, walls, lap counting, AI steering and braking.
8. **Effects**: smoke and spark particles, skid marks.
9. **Audio**: synthesized engine, tyres, wind, effects and music (Web Audio API).
10. **UI and HUD**: menu, speedometer, minimap, standings, input.
11. **Race flow**: countdown, laps, finish, results.
12. **Main loop**: update cars, camera, effects and draw each frame.

## Run it

Serve the folder and open it in a browser (WebGL needed):

```
python -m http.server 8080
```

then open http://127.0.0.1:8080
